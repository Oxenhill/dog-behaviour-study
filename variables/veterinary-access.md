# Veterinary Access — Variable File
> Started Session 11 -- the last of the four variable files named in variables/README.md's original plan to move from NOT YET STARTED to DONE. This file tracks veterinary and behavioural-care ACCESS and AFFORDABILITY, using pet-insurance penetration as the best available proxy plus direct cost-as-relinquishment-driver findings already logged elsewhere in this study. It is explanatory/contextual, like management-practices-and-culture.md, not an outcome metric -- the working hypothesis (not yet tested by any source in this study) is that better veterinary/behavioural-care access and affordability should correlate with HIGHER professional-referral rates (Core Metric 3) and LOWER cost-driven shelter surrender, independent of the management-culture variables already tracked.

## Veterinary-cost-as-relinquishment-driver (cross-referenced from existing country files, not new data)

This is a more directly-sourced, higher-quality thread than the insurance-penetration table above, and arguably the more important one for this study's purposes.

| Country | Finding | Quality | Source (already logged) |
|---------|---------|---------|--------------------------|
| Canada | >15% of owner-relinquished animals linked to inability to afford veterinary care; ~75% of responding shelters (92 total) cited this factor | A | Humane Canada 2021 report, see data/by-country/Canada.md |
| Germany | Rising veterinary costs named as a cited surrender driver, alongside owner inexperience and overwhelm | A | Deutscher Tierschutzbund May 2024 survey, see data/by-country/Germany-Austria.md |
| Austria (regional, Upper Austria) | Rising pet food/vet costs cited as a surrender driver, alongside "budget breeder" health-issue dogs | C (regional) | Pfotenhilfe OO, via ooe.orf.at, see data/by-country/Germany-Austria.md (Session 11) |

**Significance:** three separate countries' shelter-side data independently name veterinary cost/affordability as a relinquishment driver, with Canada's figure being genuinely quantified (>15% of relinquishments, ~75% of shelters). This is a distinct mechanism from this study's core management-culture thesis (training, leash norms, socialisation) -- it is an economic-access variable, not a culture/education one, and the two should not be conflated in the Phase 5 discussion even though both point toward "better-supported owners have better outcomes" in a broad sense.

## Working hypothesis for Phase 5 (not yet tested by any source in this study)
Higher insurance penetration and lower cost-driven relinquishment SHOULD, in principle, correlate with higher professional-referral rates for behaviour problems (Core Metric 3) -- an insured or financially-secure owner facing a behaviour problem has less of a cost barrier to seeking a vet or behaviourist. This study's own data cannot yet test this: Core Metric 3 (referral rate) is one of the thinnest metrics in the whole study (Australia's VetCompass 11% figure is the only real referral-rate data point found so far, per data/cross-country.md Table 3), and no single country in this file has BOTH an insurance-penetration figure AND a referral-rate figure to correlate directly. Flagged as a specific, concrete Phase 5 analysis opportunity if more referral-rate data is found in a future session, rather than asserted as an established finding here.

## Data Gaps
- No primary-source (government/academic) pet-insurance-penetration statistic was found for any country except the USA (NAPHIA) -- all others rely on undisclosed-methodology industry blogs, a real quality limitation for this table.
- Sweden's penetration figure has an unresolved 2x discrepancy (80% vs 40%+) between the two sources found this session.
- No veterinarian-per-capita or veterinary-clinic-density figures were located for any country this session -- this would be a more direct "access" measure than insurance penetration and remains a clear future-session target.
- No source combines insurance penetration or vet-cost data with this study's referral-rate (Core Metric 3) or bite/behaviour-prevalence data directly -- see the working hypothesis above.
- France, Netherlands, Japan, New Zealand, Denmark, Norway, Austria: no insurance-penetration figure located at all.
